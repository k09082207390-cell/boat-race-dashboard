# Boat Race Dashboard

ボートレース予想用の情報整理ダッシュボード試作版です。

## 現在できること
- 24場一覧を表示
- 開催場をクリック
- 1R〜12Rを選択
- 選手・モーター・ST・直前情報のデモ表示
- AI貼り付け用テキストをワンクリックでコピー

## GitHub Pagesで公開する方法
1. このリポジトリに `index.html` `style.css` `app.js` をアップロード
2. GitHub上部の `Settings`
3. 左メニューの `Pages`
4. `Build and deployment` → `Source` を `Deploy from a branch`
5. Branchを `main`、Folderを `/(root)` にして `Save`
6. 数分待つと公開URLが表示されます
